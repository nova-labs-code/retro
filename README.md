# 🕹️ Retro Web

Retro Web is a browser extension that makes websites look retro.

## 📥 How to Install

1. Download `download.zip`.
2. Extract the ZIP file.
3. Open your browser's extensions page:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
4. Turn on **Developer Mode**.
5. Click **Load unpacked**.
6. Select the folder you extracted.
7. Open a website and enjoy the retro style!

## 🔄 If You Make Changes

1. Save your changes.
2. Go back to your browser's extensions page.
3. Click **Reload** on Retro Web.
4. Refresh the website.

🕹️ **Enjoy the retro web!**
